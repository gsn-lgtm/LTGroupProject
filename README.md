# LTGroupProject

Leadership Trussville group project: **Parkway Civic Green** — a community safe room and inclusive playground.

## Send these links to the group

- Site (works now): https://raw.githack.com/gsn-lgtm/LTGroupProject/main/index.html
- Repo: https://github.com/gsn-lgtm/LTGroupProject
- Briefing PDF: https://drive.google.com/file/d/1i6IAB6p7GEscrOaoi0xEhZIJv63p9_5W/view
- Official Pages URL (after you turn Pages on once): https://gsn-lgtm.github.io/LTGroupProject/

## Turn on GitHub Pages (one time)

1. Open https://github.com/gsn-lgtm/LTGroupProject/settings/pages
2. Under **Build and deployment**, set Source to **GitHub Actions**.
3. Open the Actions tab and re-run **Deploy GitHub Pages**.

Also open the PDF in Google Drive and set sharing to **Anyone with the link** so teammates are not blocked.

## What to do

1. Read the briefing.
2. Leave comments in the group chat or open an [issue](https://github.com/gsn-lgtm/LTGroupProject/issues).
3. We take a cleaned-up version to the Leadership Trussville Board, then to the Mayor and City Council.

This is a working paper. It is not a City plan and not a bid.
